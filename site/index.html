星星人的小世界

沿着木桥拜访邻居，在花园种下三株花，陪灯里的一颗小星星找回家的路。天色暗下来以后，也可以坐着看看小镇。

进入小世界

建议使用电脑 Chrome 或 Edge。首次加载需要下载游戏资源，请稍等；当前版本需要键盘和鼠标。

第一次来这里

进入后选择“开始故事”，跟随指引走；也可以先选自由散步。

WASD 移动　鼠标 看四周　空格 跳跃　Shift 跑步
E 交谈与互动　N 地图　P 故事　H 帮助
T 换天色　O 摄影　Esc 返回 / 释放鼠标

点击游戏画面后可转动视角。声音需要点击或按键后才能开始；没听到时检查浏览器是否静音。

关于这份试玩

存档保存在当前浏览器内，不会同步到其他电脑；清理网站数据可能删除进度。摄影下载由浏览器处理。灯光和云层与 Windows 原版会有差异，手机操作与性能暂未适配。
