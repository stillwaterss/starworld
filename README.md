# 星星人的小世界 · V17

[游戏介绍](https://stillwaterss.github.io/starworld/) · [直接游玩](https://stillwaterss.github.io/starworld/play/)

一款由密斯特李发起、与 Codex 和 Claude 共同制作的免费非商业 3D 爱好者游戏。五章故事围绕迷路的小光展开，包含送信、观星、点灯、种花、飞艇与五个小故事。推荐电脑键盘鼠标。

此仓库包含完整的网页运行源文件和发布流程，不包含玩家存档、开发备份、Blender 原件和导入缓存。桌面原工程另行保留。先用 Godot 4.7.2 导入工程，再运行；GitHub Actions 自动完成导入、网页导出和发布。

网页采用单线程 Compatibility / WebGL 2，保留天空色彩校正、环境光配置、预生成寻路、点击启用声音、网页照片下载、浏览器本地存档和资源版本标识。新增居民的网页资源从约 140 MB 缩减为 33 MB；桌面原素材保持原画质。网页已去掉与 HTML 下载页重复的游戏内加载遮罩。

V17 更新了可继续、可重新开始的首页、需要点击开始的章节画、逐项操作引导、笔记本式信件、居民走出房门的动画、高处观景与完整的天灯片尾。网页版继续使用内置完整基本汉字字体，进度星形与操作勾选也包含在字库内；声音按钮位于左下角，退出按钮返回介绍页。新游戏重载后会重新准备失效的道具缓存。

V17 通过本地七组 253 项回归，另有 35 项界面与完结页检查、15 项独立存档重开检查，以及实际单文件可执行版的 69 项主线、支线和存档检查。发布前的 Chromium 检查验证真实音频和音乐信号、首页与返回、开始新游戏、章节按钮、开场后放灯、键盘移动及地图。浏览器检查使用软件渲染小窗口，不能代表用户显卡帧率。[发布检查记录](https://github.com/stillwaterss/starworld/actions)。

网页保留天空线性与 sRGB 校正，并按白天、傍晚、夜晚的同机位截图校准雾效响应。两个渲染器的雾、阴影与发光实现仍有差别，不能保证逐像素一致。GTX 1650、1280×720 的布置峰值场景中同时存在 74 盏天灯，Forward+ 与本机 Compatibility 的中位帧率约 60；该采样冻结了灯的位置来比较负载，不等于所有场景或所有浏览器始终 60 帧。

WASD / 方向键移动，Shift 跑，空格跳，E 交谈，N 地图，P 故事本，H 帮助，T 换天色，O 摄影，M 音乐。首次进入网页需要点击开始并启用声音；首次资源下载速度取决于网络。手机触控未专门适配，清理浏览器站点数据会清除网页进度。

V17.1 补充了花朵、浇水道具、水滴、远岛灯光与告别画面的进入前准备，并分批显示小镇场景。首次准备仍可能较久，页面会显示当前步骤；这只能降低首次使用的停顿，不能保证所有电脑完全无卡顿。演出加速后，镜头会等返回缓动完成再交还控制；飞艇登艇时平滑改变视野，结尾返航不再先闪回玩家镜头。第五章存档重载保留第五章进度。

介绍页的结尾折叠区提供独立送别入口（`play/?preview=ending`），从第五章码头开始，按 E 登艇。该入口明确启用内存测试进度，不读写正式旅程；刷新即可重看。`preview=flight` 是同样隔离的普通飞艇往返检查入口。开发检查记录以每次实测结果为准；自动化云端小窗口不用于报告硬件帧率。
